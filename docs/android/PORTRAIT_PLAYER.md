# 安卓竖屏播放器

2026-10-12 用户确认按截图调整播放器：竖屏视频在上，选集 / 评论在下；选集使用现有分集封面，评论从 Bangumi 获取；三个点菜单先提供已有能力。当前版本为 v0.10.0 本机预览，未创建公开发布。

## 界面与功能

- 竖屏视频使用 16:9 区域；点画面呼出 / 收起返回、更多、播放 / 暂停、进度、时间与全屏控件。播放中控件自动收起，暂停 / 加载 / 失败时可操作；系统刘海和导航区按真实 inset 留出控件安全区。
- 下方选择来源 / 线路，分集卡片显示剧照、已有分集对应 / 标题和当前选集，规则保留来源集名。封面复用既有 TMDB 剧照对应与缓存，按实际官方关联读取；缺图保留中性播放占位，不用竖海报或视频地址假作剧照。列表控件复用、图片按需采样并限制解码并发 / 排队数量。
- 评论读取 **Bangumi 当前分集讨论及回复**。切到评论时读取，每次 20 个主楼，接近底部自动追加，失败保留旧内容并明确重试；没有官方分集关联时明确提示匹配。已读评论留在本次播放页，不因横竖屏切换重新请求。
- 三个点菜单提供倍速、Anime4K 超分、音轨、字幕、外挂字幕、字幕偏移、视频详情和开源说明。全局硬解 / 解码器 / 渲染器仍在“我的 → 播放设置”。截图、投屏、弹幕、一起看、定时关闭没有实现，不提供入口。
- 横屏隐藏选集 / 评论，视频全屏显示；系统返回先回竖屏，保留会话、位置、字幕、超分及当前剧集，再次返回关闭播放器。
- 用户补充所有交互需要过渡：控件淡入 / 淡出、菜单轻移 / 淡入、选集与评论 / 来源列表淡出淡入、选中颜色及首次封面显示渐变，底部选择器沿用 Material 动画，横竖屏沿用系统旋转并补面板淡入。各阶段约 70–200 ms，触摸有涟漪反馈；关闭系统动画时立即切换。

## 数据与播放边界

继续使用原生 Activity / libmpv，不替换解码器、不增加依赖或数据库迁移。`PlayerPage.kt` 负责原生列表，`android_player_page.rs` 通过现有 Tauri 原生桥提供当前作品的安全 DTO、读取 Bangumi 与复用图片缓存，没有新增 WebView JavaScript 接口。

本地 / WebDAV 卡片以现有 `media_episode_links` 为准，13–24 对应官方 1–12 等人工对应保留，未关联文件不从列表位置猜集号。规则线路沿用既有章节缓存与选集 / 关联流程；切换只准备用户点选的一集，保留已有人工关联。规则试播没有作品锚点时不伪造 Bangumi 评论，也不写个人观看进度。

切集先打开可取消的原生加载页，再获取视频；返回取消当前代次，晚到结果不能重新打开播放器。来源窗口成功交给播放器后关闭窗口，不再把该次解析当作窗口取消。来源代理、授权、凭据、签名地址和观看记录继续沿用原有链路，不传入选集 DTO 或详情菜单。
