# 安卓评论呈现与自动追加

2026-10-13用户六张参考图确认：评论正常翻页和发现列表无需点“加载更多”。React按实际滚动容器观察底部，Native按RecyclerView可见项提前追加；请求同步去重，成功才推进源游标，追加失败保留内容、暂停自动请求并显式重试原页。切换作品 / 查询 / 题材 / 章节的旧响应废弃，隐藏页和收起回复不继续追加。

漫画 / 小说作品评论沿用Genzo主题，采用圆角卡片、头像 / 名称 / 相对时间 / 正文，标题区显示当前作品；回复在主评论下按需展开，同样显示头像与时间。动漫作品吐槽保留分隔列表、头像 / 名称 / 时间 / 评分 / 正文，7分准确显示3.5星。播放器分集讨论采用卡片、头像 / 名称 / 时间 / 正文及来源图片；漫画原生本话评论也滚动自动追加。

发现热门番组、漫画分类、小说目录及拷贝漫画 / 小说搜索复用现有分页接口。漫画首页“更多”用于进入分类页面，进入后自动追加；热门更新与Bangumi搜索没有现有分页能力，不伪造下一页。筛选和查询维持现有来源约定。

播放选择器按当前播放来源区分：规则选择实际线路与其集数；本地 / WebDAV选择当前已确认官方分集下的不同实际文件，展示文件名和来源 / 当前标记。未匹配不按文件名或列表位置推断同集，停用 / 缺失不能点击，实际选择复用已有播放入口与媒体ID。规则文件在数据库可标为local，依据规则关联辨别，不混入本地 / WebDAV文件选项。

没有新增运行依赖、数据迁移、发表评论或来源账号。当前完整OpenDesign草稿参与构建；对已修改前端的本轮增量单独保存交接补丁，避免纳入其他维护者未提交工作。最终测试 / 制品 / 用户数据核对见最新AI_HANDOFF.md。
