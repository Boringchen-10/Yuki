# 独立安卓源码基线

Yuki 从原项目 Android 分支提交 `86b6ecc1d964557fd7650d63af46d970974a714f` 继续，保留提交历史与许可证。

导入时以 0.17.2 已验证正式包的构建清单逐项核对 **406 项生产输入**，将相符的当前安卓运行源码复制到独立仓库，包括此前以交接 patch 记录的界面增量。原工作区文件未被修改或移走；没有导入临时目录、用户数据库、签名材料或临时验收脚本。

- 正式身份：`com.genzo.android`，继续原签名。
- 隔离测试身份：`com.genzo.android.readerqa`，数据与正式包分离。
- 内部 `genzo`、`genzo_lib`、数据库 / 偏好键及同步协议继续保留。
- 本次独立不引入数据库迁移，不重置版本、不改变媒体或用户记录。

旧 `*SOURCE_HANDOFF.patch` 仅作来源记录，已经包含的变更不要重新应用。未来交付直接提交本仓库实际源码。
