# Android Kazumi 兼容规则来源

## 范围与当前状态

用户于 2026-10-10 明确作废此前的内容来源限制，确认安卓接入 Kazumi 风格的规则仓库、规则搜索、选集与在线播放。本轮继续使用最新 OpenDesign 前端及 Tauri / React / Rust / Kotlin / SQLite / LibVLC 架构，版本为本机 `0.7.0` 预览，不因此创建公开 Release 或修改 Windows v0.5.0 发布资产。

这是兼容规则数据与核心行为的 Genzo 实现。没有嵌入 Kazumi 应用、Flutter / Dart 运行时或 `xpath_selector` Dart 包，也没有替换现有 LibVLC 解码内核。Bangumi 仍是动画作品与官方分集的主锚点；规则站点只提供可选播放来源，不用来源搜索结果自动覆盖作品资料。

已完成代码、前端回归、原生实体机回归与本机签名预览覆盖更新。完整交接和证据索引见本轮 `AI_HANDOFF.md`；具体站点可用性以实测样本为限。

## 用户入口

1. 在“我的 → 资料库 → 规则视频来源”打开规则仓库并按需安装，或展开“导入规则”粘贴单条 JSON / JSON 网址。已安装规则可以测试搜索、启用 / 停用、编辑 JSON、从原地址更新或移除。
2. 在视频作品详情的剧集区选择“关联规则来源”，按作品名搜索。多个已启用规则最多四个并发搜索，先返回的结果先展示；失败来源独立显示，不阻塞其他来源。
3. 进入一个结果，选择实际返回的线路与剧集。详情中的“播放”只把当前一集接到当前作品后打开原生播放器，并沿用本机观看记录。来源管理中的“试播”不绑定作品，也不保存观看记录。
4. 批量关联时勾选剧集，核对文件起始 / 官方起始编号，先查看逐行预览，再明确确认。来源 13–24、官方 1–12 可以填写 13 / 1；不会自动假定每季 12 集。默认保留同一作品已经存在的分集对应，只有明确选择替换时才重建对应。
5. 来源需要网页验证时，在独立网站页面完成验证，返回后重试搜索 / 更新选集。系统返回会先取消正在解析的网页、退回预览或选集，再关闭来源界面。

停用规则只阻止后续搜索 / 播放；移除规则会隐藏连接并使其媒体来源不可用，作品、收藏、评分、备注、分集人工对应与已有观看记录保留。重新导入同名规则复用原规则身份。该操作不会删除远程文件或用户本地媒体。

## 规则兼容能力

| 能力 | 本轮实现 |
| --- | --- |
| 规则版本 | Kazumi `api` 1–8；规则更新与导入先校验字段、地址、请求方式和大小。 |
| XPath 搜索 / 选集 | 支持结果列表、名称 / 链接、线路列表及剧集链接选择器，GET 或表单 POST 搜索。HTML 先由 jsoup 解析，标准 Android XPath 在 W3C DOM 上求值。结果 / 线路节点中的 `//` 选择器按该节点的后代上下文执行。 |
| API 搜索 / 选集 | 支持 GET / POST、query / headers、JSON / form body、嵌套与分隔字符串选集、从响应提取模板变量及 `episodePage` 模板。 |
| JSONPath | 支持 `$`、字段、非负数组下标、`[*]`、括号引号属性。与上游受限规则语法保持一致，不支持递归、过滤条件和负下标。 |
| 模板变量 | `@keyword` / `@source`，选集页面另提供 `@episodeUrl`、零起始 `@roadIndex` / `@episodeIndex` 和一起始 `@roadNumber` / `@episodeNumber`。JSON 中整个值为变量时保留数字 / 布尔等类型，URL 替换按组件编码。 |
| 网页媒体发现 | 私有 WebView 执行来源页面，发现 video / source 地址、现代 Response / XHR 返回的 HLS，或旧解析模式的 iframe `url` 参数。支持取消和有限超时，完成后销毁解析 WebView。 |
| 网站验证 | XPath / 文本 / 正则检测和 HTTP 验证响应；独立原生网页可手动输入、按规则点击按钮或执行规则验证脚本，Cookie 由系统 WebView 管理。 |
| 播放 | 媒体进入会话内的本机 MP4 / HLS 转发，再交给现有 LibVLC；不下载整部视频、不转码。 |
| HLS | 重写子播放清单、分片以及 key / map 的 URI，让每次请求携带规则 UA、Referer 和相应网站 Cookie。支持原始片段 Range 请求。 |
| 可选广告判断 | 只有规则开启 `adBlocker` 时才使用参考 Kazumi 的 discontinuity 分组时长判断；加密、byte range、map、直播或 LL-HLS 清单保留原结构。该启发式不保证每个站点都准确。 |

标准 XPath 与 Dart `xpath_selector` 不是同一个执行引擎。项目对齐常用规则的节点、相对上下文与 XPath 选择行为，不能据此宣称任何非标准扩展表达式完全等价。格式支持也不代表具体站点网络与解析已经全部验收。

## 数据与生命周期

- 新迁移 `0031_rule_video_sources.sql` 只增加规则、作品来源书签和规则剧集定位表，不重建既有作品 / 文件 / 个人记录表，也不修改已经运行的旧迁移。
- 规则在旧 `library_roots` 中使用 `rule://` 虚拟定位，并由 `rule_plugins` 明确区分 provider；沿用旧表允许的存储类型，不改变旧 CHECK。安卓来源显示与作品范围将规则归入网络来源；扫描器拒绝把它当物理目录遍历。
- 每个绑定剧集复用既有 `media_files.id`、官方分集链接与人工覆盖模型。正常播放页保存稳定页面定位；同站定位保存相对地址以便规则显式更换域名后继续使用。
- 直接媒体地址或需要刷新的 API 选集用稳定的作品 / 线路 / 剧集身份生成目录定位键，播放时重新取得地址。带时效签名的媒体 URL 不作为观看记录身份，不落入持久选集缓存。内存选集缓存有时限和容量上限。
- 更新规则、重复关联和签名刷新应保留已存在的媒体 ID 与观看位置。已有剧集属于另一作品时拒绝占用；官方分集有歧义或不存在时先保留来源条目，待用户批量核对，不生成假官方集数。
- 批量预览令牌包含规则、选集身份、作品主锚点、官方分集与已有人工对应。确认时再次核对，并用现有写入队列 / 事务及识别历史机制原子保存。
- 搜索与稳定选集使用已有 `metadata_cache` 的 `kazumi` 命名空间，有缓存时可在失败后显示旧结果和警告。缓存不是来源永久可用的依据。
- Cookie 从 Android CookieManager 只在原生 / Rust 请求内部使用，不返回给 React。网站验证与解析 WebView 没有 Tauri 应用桥；解析完成 / 取消后销毁，会话结束时关闭本机转发任务。

## 网络与播放边界

规则网页请求、解析 WebView 与验证 WebView 使用一致的桌面浏览器标识，对齐 Kazumi 的来源访问行为，避免部分站点给 Android 标识返回 App 下载页。API 规则显式请求头可以覆盖默认值；媒体请求继续保留规则指定的 UA / Referer；Referer 未填写时不自动继承网页 / iframe 地址，对齐 Kazumi 的媒体请求行为。

导入的规则可以明确使用 `http://`，因此安卓网络配置允许规则 HTTP 明文来源；用户选择 HTTP 时该连接按 HTTP 传输。HTTPS 请求继续验证证书，没有忽略证书错误或把 HTTPS 静默降级为 HTTP。

本轮可靠播放目标是 MP4 与 HLS。其他直接文件格式取决于已有 LibVLC 与设备能力；DASH / MPD 的嵌套资源重写、DRM、付费账号授权、下载管理、弹幕、超分、自动切到下一来源或整季预载不属于本轮完成承诺。

规则仓库目录按需联网读取，站点可能改版、限制访问、改变签名、要求验证或停止服务。部分结果可用不代表同一来源的全部线路 / 剧集可用。失败应给出重试 / 更新 / 切换来源入口，不能伪造成功状态或清除已有个人记录。

## 验收要求与记录

最终交付前应在独立合成数据包验证以下内容，不在用户真实库中批量绑定、扫描或清库：

- XPath GET / POST 与 API 搜索、嵌套 / 分隔选集、模板与错误反馈；网页验证后 Cookie 生效。
- 多源部分成功、取消 / 返回、分页及跨页选择、编号 13 → 1、预览失效与默认保护已有映射。
- 自建 MP4 / HLS 的真实画面 / 声音、UA / Referer / Cookie、子清单与 Range、拖动、暂停、返回及重新打开续播。
- 同名规则更新 / 停用 / 移除 / 重新导入，以及签名刷新后媒体 ID 和个人记录保留。
- 存量迁移升级、现有本地 / WebDAV 来源选择回归；常用手机 / 平板宽度及深浅主题无溢出。
