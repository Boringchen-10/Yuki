# 安卓书架操作与标签探索

2026-10-14，基于 `.tmp/android-first` 当前完整 OpenDesign，私有预览 v0.14.0，公开版仍 v0.5.2。

## 行为

- 本地详情和发现来源详情的收藏立即变化，只锁定按钮，后台保存失败恢复。单独的收藏命令只写 favorite / updated_at，不回写旧 DTO 覆盖评分、笔记或标题。
- 来源已有作品直接复用 ID；新作品先保存资料，复用已有封面文件，剩余封面异步缓存。晚到封面不能覆盖已经更改或锁定的封面。
- 书架“收藏”是独立过滤项，可结合时间顺序 / 浏览时间 / 名称 A–Z。时间顺序以原加入时间为基础，移出后重新加入更新书架时间；浏览时间来自真实打开详情，不拿作品元数据更新时间代替。
- 详情右上角三点菜单提供移除书架。状态保存在本机 app_settings 的 `android.book-shelf:<workId>`，不会执行 delete_work 或删除 / 移动媒体；作品、收藏、评分、笔记、阅读位置、下载保持原样。移出后可从发现重新加入，使用原 ID。
- 本地及来源详情标签、发现热门标签均进入发现的对应类别。Bangumi 使用 POST /v0/search/subjects 的 filter.tag，按热度与 limit / offset 分页；漫画 / 小说匹配来源分类名后使用 pathWord 请求列表。不存在同名分类时明确提示改为关键词搜索，分类请求失败仍显示错误，不掩饰成空结果。
- 标签结果下滑自动追加，失败保留内容并暂停自动重试。请求序号隔离新标签与旧响应，返回详情后复用本次会话结果。

## 依据与边界

Bangumi 参数遵循[官方 OpenAPI](https://github.com/bangumi/api/blob/master/open-api/v0.yaml)。延续既有来源网络层、封面组件、卡片、底部面板和分页观察器，没有新增依赖或数据库迁移。

书架移除状态仅影响本机安卓书架，不会删除同步作品。浏览排序从本版开始记录，未浏览作品按加入时间继续排序；没有虚构历史浏览时间。

AndroidApp.tsx / ExplorePanel.tsx 原有 OpenDesign 未提交工作保留，本轮自身增量记录在 BOOK_SHELF_SOURCE_HANDOFF.patch；该补丁已应用，不能再次应用。可用 `git apply --unidiff-zero --reverse --check` 核对。
