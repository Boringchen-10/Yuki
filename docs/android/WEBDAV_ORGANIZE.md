# 安卓目录整理与分集播放来源

2026-10-10，基线 `365a7e3`，本轮为 v0.6.0 本机验收（versionCode 6000），不创建公开 Release 或覆盖公开 v0.5.2 资产。新增迁移 0030，递增安装版本可阻止旧包直接覆盖新版数据库。

## 行为

- 待整理按已索引的真实目录浏览，入口为来源 → 分类 / 年份目录 → 作品文件夹 → 季度 / 特别篇。目录浏览不重新下载或枚举网盘正文。
- “连续识别动漫 / 自动识别此目录”逐组调用共享识别核心，可靠、无歧义时自动归档，失败或不确定时保留待整理。按钮显示实际处理组数，可在当前项处理完后停止。电影 / 电视剧仍通过单项类型选择人工核对。
- “逐个整理”提供文件勾选、类型 / 季度、候选预览、确认与跳过；确认后停留在整理流程继续下一项。代表文件只选当前勾选且可用的视频；电影初选单文件，电视剧按季度调整初选。确认提交候选绑定的代表文件 ID，避免使用过期候选。
- 作品详情的“剧集”以官方分集为主，同一集可选择本地、WebDAV 或具体文件版本。默认优先上次观看的可用文件；未关联分集的文件单独列出，不用文件顺序虚构集号。未来来源可沿用作品 / 分集 / 文件身份，本轮不实现规则源或网盘账号直连。
- 来源页“移除连接”只移除应用连接，保留网盘文件、作品、评分、笔记、观看位置、文件身份与已有缓存。文件变为不可用，其他来源仍可播放；活动扫描期间拒绝移除。新增迁移 0030 记录连接移除时间，保留关联所需内部索引，凭据通过既有凭据桥删除；不会向 WebDAV 发送 DELETE。

## 根因与范围

- 旧 WebDAV 分组固定以根目录下第一层作为作品目录，接入整个服务后会把“动漫 / 年份”等分类目录下不同作品合并。确认范围又直接用编码路径判断季度，和展示分组可能不一致。
- 虚拟来源改用最近的实际作品目录，越过季度、BD / 字幕等容器；SAF 使用 `android_documents.relative_path`，保留原始不透明文档 ID 供播放与授权。分组、确认和分集重建共用实际目录上下文。
- WebDAV / SAF 确认范围保留目录大小写；Windows 本地目录原有口径保留。混有不同命名作品的文件夹不因一个高分候选自动归档整组。
- 本轮不猜测回滚此前已经错归档的作品。已有错误关联从作品详情的重新匹配 / 分集纠错预览中核对。缺少作品名的文件仍需手动搜索。
