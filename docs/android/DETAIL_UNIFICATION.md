## 剧照

- 已入库作品继续使用原有剧照来源和人工偏移。未入库 Bangumi 作品复用相同的 TMDB 搜索、唯一季度和日期 / 集号校验，支持分割季度 / 连续集号；不会用列表下标猜图或用竖海报冒充分集图。
- 未入库只写 metadata_cache 和现有图片缓存，不创建 works、anime_episodes、媒体关联或播放进度。缓存按来源 / 条目隔离，缺凭据或更新失败保留已有图片。
- 分集图片按可见范围通过原生缓存通道读取，下载只接受服务端已核实映射中的图片地址，沿用可信域名、字节限制与并发2上限。
- 前端缓存读取 / 网络更新、手动刷新与切换作品采用请求序号和目标键，晚到的旧缓存 / 旧作品剧照不覆盖当前页面。来源未提供图片时使用中性占位。
