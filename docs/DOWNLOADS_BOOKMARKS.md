# 下载目录与阅读书签

- 「我的」仅保留下载中心；右上角齿轮打开下载设置。
- 可选择应用内部存储、手机共享存储中的应用专属目录，以及设备检测到的 SD 卡目录。显示实际路径和可用空间，保存后在本机生效。
- 后续下载使用所选位置，已有下载继续原位读取；视频任务保留各自的存储标识，旧版任务沿用内部目录。应用专属文件会随卸载清除。
- 仅 Wi-Fi 默认关闭，只保存在本机。开启后视频、漫画、小说与文件任务共用限制，离开 Wi-Fi 显示等待；用户手动暂停的任务不会自动继续。进程被系统结束后仍需手动继续中断任务。
- 下载中显示短时间窗口的实际传输速度；已知总大小时估算剩余时间，未知大小不显示估算。暂停、重新下载和长时间后台返回后重新采样。
- 「我的 → 书签」集中查看漫画 / 小说阅读器已有书签，支持搜索、类型筛选、跳转和单项删除。
- 在阅读器书签菜单选择“添加当前位置”。跳转验证作品、分组和章节，使用书签位置；删除仅移除此书签，保留阅读进度和下载。
- 复用已有 SQLite 书签表，无数据库迁移。下载目录仅存本机，不同步；不自动搬动旧下载或用户媒体。

界面沿用 React SPA、Tailwind 3、蓝白与深色主题。按 Refactoring UI §2.1 / §2.8 / §3.6，下载任务为主要内容、目录设置为次要操作；书签跳转优先，删除需确认。手机与 1280 宽度渲染、实际测试范围见 `AI_HANDOFF.md`。
