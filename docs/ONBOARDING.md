# 首次使用流程

首次使用引导随 v1.0.0 提供；发布与签名规范见 [发布指南](RELEASING.md)。

## 用户流程

1. 先展示完整的使用协议与隐私说明，主动勾选后才可点击「同意并继续」。不同意会停留在说明页，可重新阅读，或通过安卓系统返回离开应用。
2. 同意后进入规则配置，复用现有规则仓库及链接、JSON、文件和剪贴板导入。只按用户操作安装规则；导入和安装进行中不能完成引导。
3. 可在没有规则时进入应用，供本地媒体用户使用。后续从「我的 → 规则设置」管理来源；「我的 → 使用协议与隐私说明」可重读当前文本。

界面使用默认蓝白主题，显示两步进度、使用要点与完整协议。无规则时隐藏搜索 / 更新空控件，把仓库添加作为主要入口；添加成功后显示数量并突出完成。保留链接、JSON、文件和剪贴板导入。视觉走查见 [蓝白新人页](design/blue-white-onboarding.md)。

已安装旧版的用户首次升级到包含此功能的版本也需确认一次，不清库、不重建数据库、不移除既有规则或媒体。

## 持久化与启动边界

- WebView 本机存储键 `yuki-android-onboarding` 记录 `agreementVersion`、`acceptedAt` 和可选的 `completedAt`，与 `genzo-preferences` 分开，不纳入应用同步。
- 已同意但未完成时，重启恢复规则配置；全部完成后跳过引导。协议版本改变或应用数据被清除后重新确认。不要将其当作身份认证或不可篡改的法律证据。
- 存储读取失败时阻止继续并提供重试；写入失败不前进。格式损坏、无有效同意时间或版本过期的记录不作为同意。
- `FirstRunGate` 在协议确认前不挂载主应用或规则管理器；哈希路由不能跳过引导。只调用本机安全区、主题接口。
- 本机主题设置也从旧数据库的 `theme` 键读取，以保留旧版深浅模式；该读取不访问媒体或网络。前端状态与主应用共用，恢复默认会将数据库和前端模式一并设为浅色。
- 安卓原生启动仍初始化本机数据库、下载任务状态和内置索引。网络资料更新、阅读配置更新和同步循环由主应用挂载后调用 `start_android_background_services` 启动；进程内使用 `Once` 防止重复启动。继承的非安卓启动路径维持原行为。
- 同意后进入规则配置会获取现有第三方规则目录；完成引导后才启动上述后台任务。文本明确说明这些网络访问，不承诺所有功能离线或第三方不收集数据。

入口与文本：`src/android/main.tsx`、`FirstRunGate.tsx`、`LegalNotice.tsx`。原生启动：`src-tauri/src/app_startup.rs` 与 `lib.rs`。

## 协议措辞依据与限制

协议说明合法内容来源、版权、规则风险、本机数据、第三方网络请求和责任边界。开源许可不授予第三方媒体或角色权利；协议本身不保证软件及所有使用行为合法，也不排除依法不得免除的责任。没有采用“学习用途即可免责”或“24 小时删除即合法”的说法。

- [国家版权局：中华人民共和国著作权法](https://www.ncac.gov.cn/xxfb/flfg/flfg_532/202103/t20210309_50530.html)：使用行为仍需符合相应授权和法定条件。
- [人民法院公开的民法典全文](https://www.sdcourt.gov.cn/lcgtfy/374994/374995/6120123/index.html)：格式条款及免责范围应符合法律要求。
- [Kazumi 官方首次使用说明](https://kazumi.app/docs/intro/what-is-kazumi/)：参考先确认再配置规则的流程；Yuki 保留无规则进入本地媒体功能的入口。

本轮文本为产品实现草案，未经过律师审阅；不能据此宣称已完成特定地区、商店或分发渠道的法律合规审查。

## 验证

- `pnpm check`、`pnpm test`、`pnpm build`。
- `node scripts/verify-onboarding-ui.mjs`：真实引导组件配受控存储与来源接口，验证拒绝、哈希路由、错误恢复、重启、安装与自定义导入、忙碌保护和跳过规则；覆盖手机尺寸、横竖屏、深浅色、100% / 150% 字体和模拟安全区。
- `pnpm build` 后运行 `node scripts/verify-onboarding-entry.mjs`：实际生产入口配受控 Tauri 接口，验证默认模式、后台启动边界、真实外观选择、数据库模式保留、重启及恢复默认。
- `node scripts/verify-rule-catalog.mjs`：原规则仓库更新回归。
- `scripts/build-reader-qa.ps1 -Target aarch64 -Optimize`：构建隔离测试 APK；构建通过不等于安卓设备运行验收通过。

自动检查不替代设备上的系统返回键、WebView 持久化、覆盖升级和后台任务验收。实际执行结果与输出目录见根目录 `AI_HANDOFF.md`。
